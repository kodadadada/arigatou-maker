# ありがとう演出メーカー

チャンネル登録・スーパーチャット・メンバーシップ・メンバーギフト・ジュエルのお礼モーションを作って、動画（WebM / MP4）や静止画（PNG）で書き出せるブラウザツールです。`index.html` をブラウザで開くだけで使えます。わんコメのテンプレートとして OBS に置けば、スパチャなどが届いたときに自動で演出を流せます。

- 種類ごとにアイコン（ベル・コイン・王冠・プレゼント・宝石）と色が変わります。アイコンは自分の画像（ロゴやスタンプ）にも差し替えられます。スパチャは金額に合わせて色が自動で変わります
- 名前・金額・ひとことを入れられます
- キャラ画像（透過 PNG がおすすめ）、効果音（内蔵 5 種＋アップロード音）、テーマ色を選べます
- わんコメにつなぐと、届いたスパチャ・メンバー・コメントの名前（と金額）をクリックで入れられます
  - 公開ページ（github.io）から使うときは、わんコメの「設定 → API」に `kodadadada.github.io` を登録してください。ダウンロードした `index.html` を直接開く場合は登録なしでつながります
- 背景は「透過」「グリーンバック」「パステル」「画像」から選べます
  - 透過：Chrome / Edge で書き出すと背景が透明な WebM になります（OBS のメディアソースにそのまま置けます）
  - グリーンバック：編集ソフトのクロマキー用。MP4 でも書き出せます

## わんコメテンプレートとして使う（自動で流す）

1. わんコメ →「テンプレート」→ カスタムテンプレートのフォルダを開き、`arigatou-maker` フォルダ（`index.html` と `template.json`）を置く
2. ブラウザでこのツールを開き、見た目や音を整えて「わんコメテンプレートとして使う」→「設定を保存（settings.json）」を押す
3. 保存した `settings.json` を `arigatou-maker` フォルダに入れる
4. OBS に「ブラウザ」ソースを追加し、URL に `http://localhost:11180/templates/custom/arigatou-maker/?overlay` を入れる（幅 1920・高さ 1080）

- 初期設定では、スパチャ・スパステ（名前と金額）とメンバーシップギフト（贈った人の名前）で自動再生します。メンバー加入・ジュエルもチェックで追加できます
- 続けて届いたときは 1 件ずつ順番に流れます。OBS につないだ時点より前のコメントでは流れません
- 設定を変えたら `settings.json` を上書き保存するだけで、次の演出から反映されます
- テスト再生：OBS でソースを右クリック →「対話」→ 画面をクリック（または T キー）。URL の末尾に `&test` を付けると、読み込んだときに 1 回流れます
- 設定を直したいときは「設定を読み込む」で `settings.json` を開くと、前の状態から編集できます
