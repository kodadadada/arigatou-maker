# ありがとう演出メーカー

チャンネル登録・スーパーチャット・メンバーシップ・ジュエルのお礼モーションを作って、動画（WebM / MP4）や静止画（PNG）で書き出せるブラウザツールです。`index.html` をブラウザで開くだけで使えます。

- 種類ごとにアイコン（ベル・コイン・王冠・宝石）と色が変わります。スパチャは金額に合わせて色が自動で変わります
- 名前・金額・ひとことを入れられます
- キャラ画像（透過 PNG がおすすめ）、効果音（内蔵 5 種＋アップロード音）、テーマ色を選べます
- わんコメにつなぐと、届いたスパチャ・メンバー・コメントの名前（と金額）をクリックで入れられます
  - 公開ページ（github.io）から使うときは、わんコメの「設定 → API」に `kodadadada.github.io` を登録してください。ダウンロードした `index.html` を直接開く場合は登録なしでつながります
- 背景は「透過」「グリーンバック」「パステル」「画像」から選べます
  - 透過：Chrome / Edge で書き出すと背景が透明な WebM になります（OBS のメディアソースにそのまま置けます）
  - グリーンバック：編集ソフトのクロマキー用。MP4 でも書き出せます
